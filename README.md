# Ordenamiento Burbuja en Java

## Descripción
Este proyecto consiste en implementar dos métodos de ordenamiento en Java: el método Burbuja normal y el método Burbuja mejorado.

## Objetivo
Comprender el funcionamiento del ordenamiento Burbuja y comparar su comportamiento con una versión mejorada que utiliza una bandera para detectar si hubo intercambios.

## Métodos implementados

### 1. Ordenamiento Burbuja normal
Compara los elementos consecutivos del arreglo e intercambia sus posiciones cuando están en el orden incorrecto. Repite las pasadas hasta completar el proceso de ordenamiento.

### 2. Ordenamiento Burbuja mejorado
Realiza las mismas comparaciones, pero utiliza una variable booleana para detectar si hubo intercambios durante cada pasada. Si no ocurre ningún intercambio, el algoritmo termina anticipadamente.

## Pruebas realizadas
- Arreglo desordenado.
- Arreglo con valores ya ordenados.
- Arreglo parcialmente ordenado.

## Tecnología utilizada
- Lenguaje de programación: Java.
- Entorno de desarrollo: Apache NetBeans.
- Gestión del código: GitHub.

## Conclusión
La práctica permite comprender cómo funciona el ordenamiento Burbuja y cómo una bandera puede evitar pasadas innecesarias cuando el arreglo ya está ordenado.
